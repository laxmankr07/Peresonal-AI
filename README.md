Personal AI - Web Voice Assistant Platform
Overview
An embeddable, AI-powered voice assistant platform built with the MERN stack. It allows users to create and customize a smart voice assistant that provides real-time, human-like responses and smart website navigation through natural voice commands.
Technology Stack
 * Frontend: React.js, Tailwind CSS
 * Backend: Node.js, Express.js
 * Database: MongoDB Atlas
 * Authentication: Firebase Google OAuth, JWT
 * AI & API Integration: Google Gemini AI API, Web Speech API (STT/TTS)
Key Features
 * Real-time Voice Chat: Enables natural, near-zero-latency voice interaction with users.
 * Smart Website Navigation: Allows users to navigate to specific website pages using simple voice commands.
 * 1-Minute Integration: Can be effortlessly embedded into any HTML website using a single <script> tag.
 * Full UI Customization: Offers various themes (Dark, Light, Glass, Neon) to match the host platform's design.
Business Benefits
 * Provides 24/7 automated customer support, enhancing user engagement and accessibility.
 * Reduces operational costs by automating responses to common website queries.
